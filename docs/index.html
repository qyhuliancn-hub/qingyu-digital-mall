FAQ

购买前，先把这些问题说清楚。

这是开源项目吗？

不是。GitHub 仓库只用于产品展示和界面预览，不包含商城源码、数据库或安装包，也不采用 MIT/GPL 等开源许可。

可以先体验吗？

可以。演示站地址是 fkw.qyhulian.cn，演示数据仅用于展示界面和流程。

支持多域名和服务器迁移吗？

支持。同一套程序可以绑定多个域名，多个域名访问同一套商城和同一个数据库；服务器迁移时授权码不变，在新服务器重新安装并激活即可。具体额度以套餐为准。

购买后能得到源码吗？

购买获得的是商业授权、对应版本安装包、授权码和部署说明，不是无限制源码交付。二次开发、转售和再分发需要另行书面确认。

安装环境有什么要求？

原生 PHP 7.4–8.5、MySQL 5.7–8.0，Nginx 或 Apache，Linux 服务器。安装包内置环境检测和安装向导，详细步骤见授权用户文档。
